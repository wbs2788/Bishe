\section{研究背景与意义}

\subsection{生成式人工智能与文生视频技术的爆发}

生成式人工智能（Artificial Intelligence Generated Content, AIGC）是继专业生成内容（Professional Generated Content, PGC）和用户生产内容（User Generated Content, UGC）后的新型内容创作模式。近年来，该领域实现了从静态图像生成向动态视频生成的演进。早期视频生成主要依赖生成对抗网络（Generative Adversarial Networks, GANs）~\cite{goodfellow2014generative}，但受训练不稳定及模式坍塌等问题限制，难以生成高分辨率且时序连贯的长视频。随着扩散模型（Diffusion Models）~\cite{Ho2020DenoisingDP, Song2020ScoreBasedGM}与多模态对齐技术的发展，计算机视觉领域的研究重心正由判别式任务转向生成式任务。早期扩散模型因计算成本高、采样效率低，主要局限于图像生成。近期，通过对架构、采样空间及推理过程的优化，扩散模型已为文生视频技术的工程化实现提供了技术支撑。

随着 Diffusion Transformer（DiT）~\cite{dit}架构的提出，文本生成视频（Text-to-Video, T2V）在时空建模能力上显著提升。该架构利用 Transformer~\cite{vaswani2017attention}的可扩展性，使其能够处理扩散模型在隐空间中的高维序列，生成符合物理规律且时序连贯的视频。受益于 Transformer 架构的 规模法则（Scaling Law）效应及其成熟的计算优化技术，T2V 模型得以在海量数据上进行高效训练，在降低计算资源消耗的同时提升了生成的视觉质量。

其中，OpenAI 发布的 Sora~\cite{sora}在复杂场景建模与长视频生成方面具有代表性。此外，快手可灵~\cite{Kling}、阿里万象~\cite{wan2.1}及腾讯混元~\cite{hunyuanvideo}等模型也展示了高性能的生成效果。以 Wan-2.1 为例，该模型可在科研级算力支持下生成分辨率为 832×480、帧率为 16fps 的连贯视频。这些技术进展推动了视频生成技术向自动内容创作、影视预演及虚拟现实等领域的工程化应用转化。

尽管文生视频技术降低了创作门槛并提升了内容丰富度，但其在生成内容的合规性与安全性方面也带来了新的挑战。

\subsection{安全风险与伦理挑战}

随着生成式模型规模的扩大与生成质量的提升，其伴随的安全隐患逐步暴露。高保真视频生成技术在实现物理世界近似模拟的同时，也改变了内容安全的边界，主要体现在版权归属、身份鉴别及违规内容生成三个维度。

法律层面，版权侵权是文生视频技术大规模应用的主要障碍。深度模型在预训练中依赖大规模数据集，易产生记忆化现象，导致生成结果复现训练集样本。当输出内容涉及知名受保护 IP 时，即构成直接侵权。例如，2025 年 9 月迪士尼等公司针对 MiniMax 的诉讼指出，模型可根据简短指令生成受版权保护角色的高保真影像。司法实践中（如“奥特曼案”），法院已认定平台若未尽到过滤义务，需承担侵权责任。这表明生成模型可能被用于自动化侵权，对知识产权保护构成挑战。

在身份安全方面，名人身份滥用与深度伪造（Deepfake）引发了严重的社会信任危机。 
得益于时空一致性的提升，文生视频模型能够生成连贯的、难辨真伪的人物动态影像。
这种能力一旦被恶意利用，即可针对现实中的政治人物、演艺明星或普通公众制造虚假视频。 
例如，通过特定提示词生成政治人物发表不当言论的视频，可能被用于制造假新闻，干扰舆论甚至破坏选举秩序；而针对演艺明星生成的虚假商业代言或不雅视频，则严重侵犯了肖像权与名誉权。
与静态的“换脸”图像相比，视频模态的深度伪造包含动作与表情的动态变化，其欺骗性更强，传播危害性更大，给公众的信息甄别带来了极大挑战。

最后，有害内容生成是内容安全领域面临的长期顽疾。 
尽管现有的模型服务商通常会部署安全过滤机制，但在复杂的对抗攻击面前往往显得脆弱。
恶意用户可以通过精心设计的“越狱提示词”（Jailbreak Prompts）通过隐晦、隐喻或角色扮演等方式绕过文本审查，诱导模型生成暴力、血腥、色情或宣扬仇恨的违规视频。 
部分AI公司虽然具备识别暴力或裸露内容的技术能力，但在利益驱动下，往往选择不将此类保护措施严格应用于所有受版权保护或敏感的内容。
这种技术能力与防御意愿的不对等，极易导致文生视频模型被滥用于有害信息的生成与传播，对网络生态安全构成威胁。

\subsection{研究意义}

文生视频模型由于具有极高的参数规模与时空生成能力，其大规模工程应用面临严峻的内容安全挑战。构建全流程安全防御体系，对于完善 AIGC 风险管控理论、保障多媒体产业合规运行具有重要的学术价值。

\textbf{（1）应对复杂对抗攻击的技术必要性} 

当前，针对生成式视频模型的攻击手段呈现出隐蔽化与多样化趋势。传统的单一防御手段存在明显局限：输入端关键词过滤或浅层分类器难以识别利用隐喻、角色扮演或多语言混淆构建的对抗性提示词；而仅依靠输出阶段的后处理拦截，既无法移除模型权重的风险表征，又在高并发请求场景下产生显著的计算开销。因此，建立涵盖“输入端语义理解前置拦截”与“模型端风险概念内生擦除”的协同防御架构，实现预防性过滤与底层特征抑制的深度结合，是提升系统鲁棒性的关键路径。

\textbf{（2）完善视频生成安全系统化研究的缺失} 

现有关于内容安全的研究多聚焦于图像模态，且往往独立研究检测或擦除的单一环节。针对视频生成任务，由于其涉及高维时空特征，直接迁移图像防御算法易产生高昂的计算负载或破坏生成视频的时序连贯性。本研究提出的基于大语言模型思维链的检测方法与基于潜空间偏好优化的擦除算法，旨在解决视频模态下的效率瓶颈与时空一致性问题，并将二者集成于统一框架内。该架构通过协同优化计算资源分配与运动先验保护，为视频生成安全研究提供了系统化的技术支撑。

\textbf{（3）推动 AIGC 产业合规与知识产权保护的实施} 

随着全球范围内生成式人工智能监管法规的相继出台，内容合规已成为 AIGC 行业健康发展的核心约束。本研究所构建的防御体系，一方面通过高效的概念擦除技术，允许服务商在不重新训练模型的前提下，针对性地削弱受版权保护的视觉元素或特定身份特征，降低知识产权侵权与肖像权纠纷风险；另一方面，前置安全检测机制能有效拦截违规生成请求，强化平台侧的内容审查能力。该研究对于推动文生视频技术从实验室环境向大规模商业场景转化，构建可信、受控的人工智能应用生态具有明确的工程指导意义。

\section{本文主要研究内容}

针对现有文生视频防御方案在输入端隐晦攻击识别能力不足、模型端概念擦除计算代价高且易导致时空逻辑受损等挑战，本文构建了一套覆盖输入意图识别与模型权重优化的多层级安全防御方案。具体研究内容涵盖以下三个方向：

\subsection{基于思维链增强的视频生成前置安全检测}

针对输入端恶意提示词具有的高隐蔽性、语义歧义以及对抗性“越狱”攻击等特征，本文提出一种基于大语言模型（Large Language Model, LLM）推理增强的前置过滤机制。

（1）模型微调与领域对齐： 以轻量化模型 Llama-3.1-8B ~\cite{dubey2024llama}为基座，利用参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）技术，在构建的安全语料库上进行有监督微调，旨在优化模型对视频生成场景下特定安全策略的遵从性。

（2）推理增强与逻辑校准： 设计“策略即提示（Policy-as-Prompt）”机制，将抽象的安全准则转化为结构化的系统指令；同步引入“思维链（Chain-of-Thought, CoT）”机制~\cite{wei2022chain}，要求模型在输出判定结果前生成显式的逻辑推理步骤。该机制增强了模型对隐喻表达、角色扮演及多语言混淆等边界样本（Boundary Samples）的语义判别效能，从而提升了对违规生成请求的拦截成功率。

\subsection{基于潜空间直接偏好优化的视频概念擦除}

针对图像擦除算法迁移至视频领域时存在的计算负载过高及视频时序逻辑受损问题，本文提出一种无需像素解码的高效视频概念擦除方案。

（1）Latent-DPO 算法： 提出潜空间直接偏好优化（Latent Direct Preference Optimization, Latent-DPO）算法，旨在避开计算成本高昂的逐帧像素级解码过程。该方法通过在统一噪声输入与时间步条件下，构建由“风险概念样本”与“无概念安全样本”组成的潜变量轨迹对，直接在扩散模型的隐空间内进行去噪路径的偏好对齐，从而降低了模型微调过程中的显存消耗与时间开销。

（2）时空-语义对齐损失（Spatiotemporal–Semantic Alignment Loss, STSA）： 为缓解概念擦除过程中常见的视频帧间闪烁及非目标语义偏移问题，设计了基于交叉注意力机制的时空-语义对齐损失。该损失函数通过对查询（Query）与键（Key）交互上下文的分布约束，在剥离目标风险概念的同时，尽可能维持视频原有的时序连贯性与结构完整性。

（3）VCE-24K 基准数据集构建： 针对视频概念擦除领域缺乏标准化训练数据的现状，利用冻结的 Wan-2.1 模型与自动化筛选流水线，构建了包含 24,000 对样本的视频概念偏好数据集 VCE-24K。该数据集为视频模态下的概念剥离研究提供了基础数据支撑与性能评估基准。

\subsection{文生视频全流程安全防御系统设计与实现}

为验证前述检测算法与擦除策略在集成环境下的有效性，本文开发了一套面向文生视频的内容安全防御原型系统，旨在实现算法的工程化验证。

（1）双轨协同与受限资源调度设计： 构建了“前置文本检测与后置视频擦除”的双轨协同防御架构，并针对消费级单卡设备显存受限的工程痛点，设计了轻量化语言模型与高维视频扩散模型间的动态显存调度与时分复用策略，提升了防御系统在受限算力环境下的部署可行性。

（2）防御工作流机制： 系统集成了“前置预检—推理干预—后验评测”的级联防御流程。首先，利用 LLM 检测器对用户输入的文本指令进行语义风险筛查；其次，针对触发版权风险的合规请求，调用经 Latent-DPO 微调的生成模型，以生成有效降低侵权风险的视频内容；最后，集成 VBench 等评测工具对生成视频进行自动化质量评估与合规性复核。

（3）实验验证与性能分析： 本文在恶意攻击拦截、版权 IP 保护等具体场景下对原型系统进行了功能测试与性能评估。实验结果验证了该防御体系在处理对抗性提示词时的鲁棒性，以及在实际应用场景中的技术可行性与防御效能。

本文针对文生视频模型的安全防御问题，围绕国内外研究现状、前置安全检测、模型概念擦除及系统集成应用四个方面展开研究。图\ref{fig:overall_framework}展示了本文研究内容的总体逻辑框架及各章节之间的关联。全文共分为六章，各章节的具体安排如下：

第一章 绪论。 阐述文生视频技术的发展背景及其在版权侵权、有害内容生成等方面面临的安全挑战。在此基础上，明确本文的研究意义、主要研究内容及创新点，并给出论文的总体结构安排。

第二章 国内外研究现状。 系统梳理文生视频模型的发展脉络，并对现有的生成式内容安全防御技术进行综合评述。通过剖析现有方法在应对视频高维时空特性与隐晦对抗攻击时暴露出的局限性，论证本文提出新型防御架构与构建专属验证数据集的必要性。

第三章 基于思维链增强的视频生成前置安全检测。 针对输入端恶意提示词的隐蔽性与歧义性，提出一种基于大语言模型的前置检测方法。本章首先基于多类安全风险体系，构建了包含隐喻及复杂对抗样本的多模态检测数据集；随后介绍了如何利用参数高效微调技术将安全策略整合至 Llama-3.1 模型中，并设计基于思维链的推理机制与“策略即提示”机制，以提升模型对隐性风险的识别精度与拦截能力。

第四章 基于潜空间偏好优化的视频概念擦除方法。 针对模型权重中存储的风险概念移除问题，提出一种高效的 Latent-DPO 概念擦除算法。本章首先介绍了利用自动化筛选流程构建的视频概念擦除基准数据集 VCE-24K；随后推导了在潜空间进行直接偏好优化的理论公式，阐述如何通过构建正负偏好路径在无需像素解码的前提下约束去噪过程。同时，提出时空-语义对齐损失（STSA），以解决擦除过程中可能出现的视频时序不连贯与非目标语义偏移问题。

第五章 文生视频全流程安全防御系统的设计与实现。 基于上述核心算法，开发并实现了一套集成式安全防御原型系统。本章详细描述系统的总体架构、功能模块及单卡受限资源下的模型动态调度技术，展示“预检—干预—评测”三个阶段的双轨协同工作流程，并通过恶意攻击拦截与版权 IP 保护等场景测试系统的防御效能与稳定性。

第六章 总结与展望。 对全文的研究工作与核心成果进行总结，客观分析当前研究中存在的不足之处，并对未来的研究方向进行展望。
